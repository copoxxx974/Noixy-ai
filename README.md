# Nokshi AI — Xcode project starter

This folder contains a basic SwiftUI Xcode project structure for Nokshi AI.

## Important
- This is a starter project, not a signed/installable `.ipa`.
- An Apple-supported macOS/Xcode build environment is required to build an iOS app.
- Installing on a physical iPhone generally requires Apple code signing.
- Chat responses are placeholders until an AI backend/API is connected.
- Change the bundle identifier to one you own before signing/releasing.
